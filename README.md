# 🐍 Curso de Python 3 do Básico ao Avançado (com Projetos Reais)

Repositório criado para armazenar e organizar todos os códigos, exercícios e projetos desenvolvidos ao longo do curso de Python 3 da Udemy, ministrado pelo instrutor Luiz Otávio Miranda. O foco do repositório é a aplicação prática de lógica de programação, desenvolvimento web, interfaces gráficas, bancos de dados e engenharia de software.

---

## 🚀 O que estou aprendendo

O curso é focado em projetos reais e cobre desde a sintaxe mais básica até tópicos altamente avançados do mercado:

*   **Lógica de Programação & Python Básico:** Instalação, variáveis, estruturas condicionais e de repetição.
*   **Programação Procedural & Funcional (Intermediário):** Criação de funções, escopos, empacotamento, dicionários e compreensão de listas (*List Comprehension*).
*   **Programação Orientada a Objetos (POO Avançado):** Classes, herança, polimorfismo, interfaces e aplicação profunda de **Design Patterns (Padrões de Projeto GoF)**.
*   **Interfaces Gráficas (GUI):** Desenvolvimento de aplicações desktop modernas utilizando **PySide6 (Qt 6)**.
*   **Desenvolvimento Web:** Criação de sites, sistemas e APIs robustas utilizando o framework **Django**.
*   **Automação e Web Scraping:** Coleta de dados e automação de tarefas com **Selenium**.
*   **Bancos de Dados Relacionais:** Modelagem, consultas SQL e manipulação de dados utilizando **SQLite3, MySQL e MariaDB**.
*   **Qualidade de Código:** Testes automatizados e desenvolvimento orientado a testes (**TDD básico**) usando *Pytest* e *Unittest*.
*   **Módulos Extras:** Expressões Regulares (RegEx), comandos Unix/Linux (deploy no Google Cloud Platform com chaves SSH), além de fundamentos de HTML5 e CSS3.

---

## 📂 Estrutura do Repositório

O projeto é organizado em pastas sequenciais para facilitar o estudo e a revisão do conteúdo:

*   `aulaXXX/`: Códigos, desafios e anotações divididos por tópicos do curso.
*   `python_basico_intermediario/`: Scripts dedicados à fundamentação da linguagem.
*   `.env-exemplo`: Modelo de configuração para variáveis de ambiente locais (ex: dados de conexão com bancos de dados).
*   `.gitignore`: Arquivo de configuração para impedir que o Git rastreie arquivos desnecessários (como ambientes virtuais `.venv/` ou configurações locais do editor `.vscode/`).
